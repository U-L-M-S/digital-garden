>[[wiki/XML\|XML]] (Extensible Markup Language) ist eine Markup-Sprache für strukturierte Datendarstellung.

>>Es ermöglicht plattformunabhängigen Datenaustausch mit selbstbeschreibender Struktur.

>[!important] 
>**XML-Eigenschaften:**
>- Hierarchische Struktur
>- Tags mit Attributen
>- Schema-Validierung möglich
>- Menschenlesbar

>[!example] 
>```xml
><?xml version="1.0" encoding="UTF-8"?>
><person>
>    <name>Max Mustermann</name>
>    <alter>25</alter>
>    <email>max@example.com</email>
></person>
>```

>[!note] 
>Verbose aber selbstdokumentierend, heute oft durch [[wiki/JSON\|JSON]] ersetzt.
