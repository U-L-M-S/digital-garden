>Die **Java Virtual Machine (JVM)** ist eine Laufzeitumgebung, die [[wiki/Java\|Java]]-Programme ausführt, indem sie den [[wiki/Java\|Java]]-Bytecode in maschinenspezifischen Code übersetzt. 
>>Sie sorgt für Plattformunabhängigkeit und verwaltet Speicher, Garbage Collection und Sicherheitsfunktionen. Dadurch läuft ein [[wiki/Java\|Java]]-Programm auf jeder Plattform, die eine JVM unterstützt.

```bash
java --help

- -version          Zeigt die Java-Version an.
- -classpath/-cp    Legt das Klassenverzeichnis fest.
- -jar              Startet eine Anwendung direkt aus einer JAR-Datei.
- -X...             Erweiterte (nicht standardisierte) Optionen zur Speicherverwaltung und Diagnose.

```
