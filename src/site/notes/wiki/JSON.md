>[[wiki/JSON\|JSON]] (JavaScript Object Notation) ist ein leichtgewichtiges Datenformat für den Datenaustausch.

>>Es ist menschenlesbar, kompakt und wird hauptsächlich in Web-[[wiki/API\|API]]s verwendet.

>[!important] 
>**JSON-Datentypen:**
>- Strings, Numbers, Booleans
>- Objects (Key-Value-Paare)
>- Arrays
>- null

>[!example] 
>```json
>{
>  "name": "Max Mustermann",
>  "alter": 25,
>  "skills": ["Java", "Python", "SQL"],
>  "aktiv": true
>}
>```

>[!success] 
>Standard für [[wiki/REST API\|REST API]]s und moderne Web-Anwendungen.
