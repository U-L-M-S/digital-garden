# Die [[wiki/Server\|Server]]-Reise: Von Hardware zu Cloud Services

> Diese Module bauen aufeinander auf - wie eine Treppe vom einfachen [[wiki/Server\|Server]] bis zu komplexen Cloud-Diensten.

**Der Weg:**

1. **[[wiki/Server - Grundlagen\|Server - Grundlagen]]** - Du lernst erst mal was ein [[wiki/Server\|Server]] überhaupt ist und wie er funktioniert

2. **[[wiki/Server - Virtualisierung\|Server - Virtualisierung]]** - Statt 10 physische [[wiki/Server\|Server]] zu kaufen, machst du aus einem [[wiki/Server\|Server]] zehn virtuelle - spart Geld und Platz

3. **[[wiki/Active Directory und GPOs\|Active Directory und GPOs]]** - Jetzt wo du [[wiki/Server\|Server]] hast, brauchst du eine zentrale Verwaltung für User und Computer in Windows-Umgebungen

4. **[[wiki/Linux Grundlage\|Linux Grundlage]]n** - Nicht alles läuft auf Windows - Linux ist das Betriebssystem für die meisten Web-Server weltweit

5. **[[wiki/LAMP Stack\|LAMP Stack]]** - Mit Linux Wissen baust du jetzt komplette Web-Server (Linux + Apache + MySQL + PHP)

6. **[[wiki/Nextcloud\|Nextcloud]]** - Als Praxisbeispiel: Ein echter Cloud-Service der auf deinem [[wiki/LAMP Stack\|LAMP Stack]] läuft
