>[[wiki/Datenbank\|Datenbank]] speichert und verwaltet strukturierte Daten persistent.
>>In [[wiki/Docker\|Docker]] oft als separater [[wiki/Docker Container\|Docker Container]] Service für Web Anwendungen.

>[!tip] Datenbank Container
>- **PostgreSQL** - `postgres:14`
>- **MySQL** - `mysql:8.0`
>- **MongoDB** - `mongo:latest`  
>- **Redis** - `redis:alpine`
>- Immer [[Volumes\|Volumes]] für Datenpersistenz nutzen!
