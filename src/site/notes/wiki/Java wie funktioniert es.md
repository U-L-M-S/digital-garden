# Quellcode
> Als Startpunkt stell dir vor, wir haben folgenden Code in einer Datei, die **HelloWorld.java** heißt.

```java
class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!"); 
    }
}
```

>Wie du bereits im klassischen "Hello World"-Code sehen kannst, ist alles in einer [[wiki/Klasse\|Klasse]] (HelloWorld) gespeichert.

Die [[wiki/Funktion\|Funktion]] `main()` ist der **Starter** des Programms.
>[!note] Eigentlich... [[wiki/Programmierung Methode\|Programmierung Methode]]. Da wir in [[wiki/Java\|Java]] keine  echten [[wiki/Funktion\|Funktion]]en haben.

Nun hat die [[wiki/Funktion\|Funktion]] drei Begriffe bei sich:
- public: Der [[wiki/Zugriffsmodifikator\|Zugriffsmodifikator]], der festlegt, dass die [[wiki/Programmierung Methode\|Programmierung Methode]] von überall aufgerufen werden kann.
- [[wiki/static\|static]]: ([[wiki/Static Java Methode\|Static Java Methode]]) bedeutet, dass die [[wiki/Programmierung Methode\|Programmierung Methode]] ohne Erstellen eines Objekts der [[wiki/Klasse\|Klasse]] aufgerufen werden kann.
- void: [[wiki/Rückgabewerttyp\|Rückgabewerttyp]]; die [[wiki/Programmierung Methode\|Programmierung Methode]] hat keinen Rückgabewert.

Der Methodenaufruf "`System.out.println("Hello, World!");`" macht nichts anderes, als "Hello, World!" in der Console auszugeben.

# Kompilierung ([[wiki/Compiler\|Compiler]])
>Nun mit [[wiki/javac\|javac]] können wir **HelloWorld.java** kompilieren.

```bash
javac HelloWorld.java
```

Somit wird eine HelloWorld-Datei als [[wiki/Binärzahl\|Binär]] erstellt.

# Java Virtual Machine (JVM) / [[wiki/Interpreter\|Interpreter]]
>Jetzt können wir endlich den Code ausführen.

```bash
java HelloWorld
```

Mit diesem Befehl wird die [[wiki/Binärzahl\|Binär]]-Datei in der [[wiki/Java\|Java]] Virtual Machine ausgeführt, und das Ergebnis wird an unsere Hostmaschine zurückgegeben.
