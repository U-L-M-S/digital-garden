>[[wiki/IPSec\|IPSec]] (Internet Protocol Security) ist ein Framework für sichere IP-Kommunikation.

>>Es bietet [[wiki/Authentifizierung\|Authentifizierung]], [[wiki/Verschlüsselung\|Verschlüsselung]] und [[wiki/Integrität\|Integrität]] auf Netzwerk-Layer.

>[!important] 
>**IPSec-Modi:**
>- **Transport Mode**: Nur Payload verschlüsselt
>- **Tunnel Mode**: Komplettes IP-Paket verschlüsselt

>[!example] 
>**IPSec-Protokolle:**
>- **AH** (Authentication Header): [[wiki/Authentifizierung\|Authentifizierung]]
>- **ESP** (Encapsulating Security Payload): Verschlüsselung
>- **IKE** (Internet Key Exchange): Schlüsselaustausch

>[!success] 
>Standard für Site-to-Site [[wiki/VPN\|VPN]]s und sichere Netzwerk-Kommunikation.
