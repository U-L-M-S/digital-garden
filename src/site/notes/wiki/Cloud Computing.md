> Bereitstellung von IT-Ressourcen über das [[wiki/Internet\|Internet]] ([[wiki/Server\|Server]], Speicher, [[wiki/Software\|Software]]). Nutzer zahlen nur, was sie verbrauchen.

> [!note] **Cloud-Arten**:
> 
> - **Public Cloud**  
>     Öffentliche Cloud, z.B. AWS, Azure, Google Cloud – Ressourcen werden mit anderen geteilt.
>     
> - **Private Cloud**  
>     Exklusiv für ein [[wiki/Unternehmen\|Unternehmen]] – mehr Kontrolle und Sicherheit.
>     
> - **Hybrid Cloud**  
>     Kombination aus Public und Private Cloud.
>     
> - **Community Cloud**  
>     Mehrere Organisationen teilen sich eine Cloud-Infrastruktur (z.B. Behörden).
>     

> [!tip] **Was wird „abgegeben“ / bereitgestellt?**
> 
> - **Rechenleistung** (virtuelle Maschinen, [[wiki/Server\|Server]])
> - **Speicher** (z.B. Datenbanken, Object Storage)
> - **[[wiki/Software\|Software]]** ([[wiki/SaaS\|SaaS]]: z.B. Google Docs, Office 365)
> - **Netzwerkdienste** (z.B. [[wiki/VPN\|VPN]], Firewalls)
> - **Entwicklungsumgebungen** ([[wiki/PaaS\|PaaS]]: z.B. [[wiki/Vercel\|Vercel]])
> - **Infrastruktur** ([[wiki/IaaS\|IaaS]]: z.B. AWS EC2, Microsoft Azure VM)

>

>
