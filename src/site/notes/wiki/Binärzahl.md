>Es ist ein Zahlsystem, bei dem man nur **zwei** Zahlen benutzt (1 und 0). 

|     | -   |       |     |
| :-: | --- | :---: | :-: |
|  1  | -   | True  | ON  |
|  0  | -   | False | OFF |

Wir wissen, dass 8 [[wiki/Bit\|Bit]]s genau 1 [[wiki/Byte\|Byte]] entsprechen.

>Es gibt mehrere Möglichkeiten, aber oft wird das hier verwendet:

96 zu Binär

| Zahl  | :2  | Ergebnis | Rest |
| :---: | :-: | :------: | :--: |
|  96   | :2  |    48    |  0   |
|  48   | :2  |    24    |  0   |
|  24   | :2  |    12    |  0   |
|  12   | :2  |    6     |  0   |
|   6   | :2  |    3     |  0   |
|   3   | :2  |    1     |  1   |
|   1   | :2  |    1     |  1   |
| **0** |     |          |      |

Jetzt müssen wir den Rest **rückwärts** zählen.
D.h: **96** in Binär ist **1100000**

**11001101**

Die Zahl **11001101** in Tabelle einsetzen 

| 2¹⁰ | 2⁹  | 2⁸  | 2⁷  | 2⁶  | 2⁵  | 2⁴  | 2³  | 2²  | 2¹  | 2⁰  |
| :-: | :-: | :-: | :-: | :-: | :-: | :-: | --- | --- | --- | --- |
|     |     |     |  1  |  1  |  0  |  0  | 1   | 1   | 0   | 1   |

überall, wo eine **1** steht, summieren. D.h 
2⁰+2²+2³+2⁶+2⁷
1 + 4 + 8 + 64 + 128 = 205

 **11001101** = **205**

>>**0–9** und **A–F** (A=10, B=11, C=12, D=13, E=14, F=15).

Jede Hexadezimalzahl kann direkt in [[wiki/Binärzahl\|Binär]] umgewandelt werden, da jede Hex-Ziffer genau 4 Bits entspricht:
