>[[wiki/TOM\|TOM]] (Technische und organisatorische Maßnahmen) sind Sicherheitsvorkehrungen zum Schutz personenbezogener Daten.

>>Sie sind nach DSGVO Art. 32 verpflichtend zur Gewährleistung angemessener Sicherheit.

>[!important] 
>**Technische Maßnahmen:**
>- [[wiki/Verschlüsselung\|Verschlüsselung]]
>- Zugangskontrollen
>- Firewalls
>- Backup-Systeme

>[!important] 
>**Organisatorische Maßnahmen:**
>- Datenschutz-Richtlinien
>- Mitarbeiter-Schulungen
>- Incident Response Plan
>- Löschkonzepte

>[!example] 
>**TOM-Dokumentation:**
>- Risikoanalyse
>- Maßnahmenkatalog
>- Wirksamkeitsnachweis
>- Regelmäßige Überprüfung
