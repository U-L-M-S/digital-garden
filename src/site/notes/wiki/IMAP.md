**IMAP (Internet Message Access Protocol)** - Protokoll für E-Mail-Synchronisation über [[wiki/PORT\|Port]] 143.
E-Mails bleiben auf Server - flexibler als [[wiki/POP3\|POP3]], Zugriff von mehreren Geräten.
